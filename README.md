# Featured Project

## 🚁 Smart Aerial Navigation System

**AI-Powered Autonomous Drone Navigation & Surveillance System**

A real-time intelligent drone system combining **Computer Vision, Face Recognition, Object Tracking, Autonomous Navigation, Voice Control, and Edge-Assisted AI**.

The system is designed around a DJI Tello drone and a ground-station architecture where computationally intensive AI workloads can be processed externally while maintaining responsive drone control.

### Core Capabilities

* 🎯 Real-time object and face detection
* 👤 Face identification and target assignment
* 🔒 Target lock and intelligent following
* 🚁 Autonomous flight mode
* 🎮 Manual keyboard control
* 🎙️ Voice-controlled drone operations
* 📡 Real-time UDP video streaming
* ⚡ Low-latency control architecture
* 🧠 Edge-assisted AI inference
* 🎥 Real-time computer vision pipeline
* 🛬 Automated landing behavior
* 📊 AI-driven navigation and surveillance

### Technology Stack

`Python` `OpenCV` `YOLO` `ONNX Runtime` `Computer Vision` `Face Recognition` `DJI Tello` `UDP` `Streamlit` `Deep Learning`

> **Engineering focus:** real-time inference, low-latency communication, stable control loops, asynchronous vision processing, and practical deployment of AI models.
